# 📝 Text Summarization (FastAPI + React)

A simple, fast **text summarizer**: paste long text → get a clean summary.  
Built with **FastAPI + HuggingFace Transformers** on the backend and **Vite + React** on the frontend.

> Tamil-friendly guide included below. ✅

---

## ✨ Features
- Abstractive summarization (DistilBART: `sshleifer/distilbart-cnn-12-6`)
- Clean UI (inline CSS, no extra UI libs)
- Copy-to-clipboard, word/char counter
- CORS enabled, robust fetch (timeout/error messages)
- Works fully **offline** after first model download
